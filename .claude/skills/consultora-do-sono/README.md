# Consultora do Sono 🌙 — Skill do Claude Code

Uma consultora do sono infantil personalizada, direto no Claude Code. A "Lua" faz perguntas sobre a rotina do bebê, monta um plano sob medida, resolve despertares e sonecas curtas, e traz dicas, apps e links de referência — sempre priorizando o sono seguro e com tom acolhedor.

Focada na fase de **4–6 meses**, mas se adapta conforme o bebê cresce.

## Como usar

No Claude Code, é só chamar:

```
/consultora-do-sono
```

Ou simplesmente escrever algo como *"minha bebê está acordando toda hora à noite, me ajuda"* — a skill é acionada automaticamente quando o assunto é sono do bebê.

Aí é só conversar: conte a idade, a rotina de hoje e a maior dificuldade. A Lua devolve um diagnóstico e um plano.

## O que tem dentro

| Arquivo | Conteúdo |
|---|---|
| `SKILL.md` | A persona (Lua), os princípios e o fluxo da consulta |
| `rotinas.md` | Janelas de sono por idade + exemplos de rotina (4, 5 e 6 meses) |
| `solucao-de-problemas.md` | Os problemas de sono mais comuns e como resolver |
| `sono-seguro.md` | Regras não-negociáveis de sono seguro |
| `referencias.md` | Apps, livros, links e itens úteis pra casa |

## Importante

Esta skill dá suporte de **rotina e comportamento** de sono. Ela **não substitui o pediatra** — qualquer sinal de saúde deve ser avaliado por um médico.
