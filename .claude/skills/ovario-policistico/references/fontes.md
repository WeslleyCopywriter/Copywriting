# Fontes e bibliografia

> Fontes usadas para construir esta skill. Prioridade para a **Diretriz
> Internacional Baseada em Evidências de 2023** e para meta-análises/revisões de
> 2023–2026. Conteúdo educativo — sempre confirme com seu médico.
>
> Transparência: parte do conteúdo foi extraída de resumos indexados dessas
> fontes (o acesso direto a alguns textos completos foi bloqueado durante a
> pesquisa). Os números foram transcritos das fontes citadas; onde a evidência é
> fraca ou os estudos divergem, isso está sinalizado no texto. Para uso clínico,
> os limiares numéricos devem ser confirmados no documento original da diretriz.
