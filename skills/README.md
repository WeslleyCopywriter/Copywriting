# Skills

Skills personalizadas do Claude Code.

## imovel-comprar-ou-construir

Consultor de decisão imobiliária. Ajuda a decidir entre **comprar pronto**, **construir** ou **aguardar** um momento melhor — rodando os números reais (custo total de cada caminho, custo de oportunidade, comprometimento de renda) e devolvendo uma recomendação com o porquê.

**Como acionar:** descreva sua situação (renda, entrada, imóvel/terreno em vista, prazo) ou pergunte diretamente, ex: *"compro pronto ou construo?"*, *"vale a pena esperar os juros caírem?"*, *"roda os números da casa pra mim"*.

**Instalação:** copie a pasta `imovel-comprar-ou-construir/` para o diretório de skills do Claude Code (`~/.claude/skills/`).
